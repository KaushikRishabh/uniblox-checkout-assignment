# Checkout and rewards

A TypeScript HTTP backend for the Uniblox checkout and rewards assignment.
No runtime packages, credentials, frontend, or payment services are required.

## Development plan

1. Implement explicit cart, inventory, order and coupon invariants in a synchronous store.
2. Add a small JSON HTTP adapter and deterministic seed products.
3. Exercise overlapping HTTP requests, failed checkout, retries and report reconciliation.
4. Document selected semantics, API examples, limitations and AI assistance.
